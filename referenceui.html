How it works

Create a link while signed in, share /#/r/your-code, and every visit is logged with its timestamp, device, browser and referrer. Redirects are served from an in-memory cache, creation is rate limited (5 links per minute), sessions use signed JWT-style tokens, and links support custom aliases and expiry dates. This is a front-end-only build: data lives in this browser's localStorage. For production, swap the storage layer for PostgreSQL + Redis behind a real API — the UI is written around the same shorten / redirect / stats operations.
