# Challenge Triage
1. Read official brief, rubric, README, and repo instructions.
2. Summarize target user, problem, required outcome, constraints, judging, and submission.
3. Identify the smallest demo-critical end-to-end flow.
4. Ask one concise batch of consequential questions before coding.
5. Separate must-haves from optional ideas.
6. Update project brief, durable decisions, and task state.
7. Never invent requirements or pre-build speculatively.
